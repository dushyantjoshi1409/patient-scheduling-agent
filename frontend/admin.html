System Architecture — 3 Agents

🤖 Scheduling Agent

Gemini 3.8 Flash (Google)

The main conversational agent. Handles patient requests, calls 6 tools (search doctors, check availability, book/cancel/reschedule appointments), maintains multi-turn state.

Why Gemini? Free tier, native function calling, fast inference. Flash variant balances cost and quality.

🎭 Simulated Patient

Qwen 3.8 27B (Groq)

Plays the patient role during eval. Follows persona scripts (frustrated patient, vague requester, emergency case, etc.) and responds naturally in conversation.

Why Groq/Qwen? Different provider than the agent — avoids self-evaluation bias. Groq's speed makes multi-turn eval fast. Smaller model keeps patient responses natural and concise.

⚖️ Eval Judge

Qwen 3.8 27B (Groq)

Reads full transcripts and scores on 5 dimensions (Task Completion, Safety, Conversation Quality, Tool Use, Guardrail Compliance). Each 1-5, total /25.

Why separate judge? Cross-model evaluation is more objective than self-assessment. Reliable structured JSON output.

🔧 Prompt Improver

Qwen 3.8 27B (Groq)

Analyzes failure patterns → identifies root causes → generates surgical prompt patches → preserves safety guardrails. Writes new prompt versions to DB.

Why? Closes the self-improvement loop. Before/after comparison catches regressions.

Tech Stack

Backend

FastAPI — async Python, auto-docs at /docs
SQLAlchemy — async ORM with asyncpg driver
PostgreSQL 16 — conversations stored as JSONB
Pydantic — request/response validation

Agent Tools (6)

search_doctors — by name or specialty
check_availability — for doctor + date range
book_appointment — creates booking
cancel_appointment — by appointment ID
reschedule_appointment — cancel + rebook
get_appointment_details — lookup by ID
